## Scope

Source response to `apps/wms-mobile/handoff/UAT_SCAN_20261017/TC_UAT_05/BE_HANDOFF.md`.
Contract: `docs/contracts/auth-session-replacement-v1.json`.

Login B replaces A across the account, including web/native/admin clients. There
is no inferred device identity or role exception. Incorrect passwords, denied
transport and an unfinished/failed MFA challenge must not replace A. Refresh and
warehouse selection do not create replacement login families.

The old family is persistently marked and revoked while the parent user row is
locked. Its old access JWTs are refused by the global credential middleware,
including JWTs issued before a refresh rotation. A late refresh from that
replaced family is refused without revoking B. New-session token generation is
in the same transaction; an exception rolls the replacement back.

## FE/App Handling

| HTTP / Code | Required handling |
| --- | --- |
| 401 `AUTH_SESSION_REPLACED` | Terminal for that auth generation. Stop commands and refresh. Ask for explicit login; do not retry owner writes. |
| 401 `AUTH_SESSION_REQUIRED` | Legacy access JWT has no session identity under enabled policy. Require explicit login. |
| 401 `AUTH_SESSION_EXPIRED` | Family expired/revoked; not proof of replacement. Existing expiry handling applies. |
| 401 `UNAUTHENTICATED` | Existing invalid/expired-token semantics. Never replace a terminal replacement result with refresh retry. |
| 403 | Keep permission/account/origin semantics separate from replacement. |
| 503 / network failure | Not proof of replacement. Preserve original owner identity and UNKNOWN state. |

Read `data.account_session_policy.version = auth-session-replacement-v1` and its
`enabled` value from auth user/profile payload. Browser refresh stays in the
HttpOnly cookie. No web domain is added to the body-token allowlist.

An idle/offline client cannot be remotely disconnected without a supported
event. Check `GET /api/v1/auth/me` on foreground and before resuming commands;
60-second checks while foreground are recommended. BE refuses the next
authenticated request after replacement. An already admitted request can still
complete. FE must discard late responses from an obsolete local auth generation.

Do not END the old work shift, delete/cancel its drafts, clear its journal, or
attach its UNKNOWN requests to B. Auth replacement is not a recovery contract.
